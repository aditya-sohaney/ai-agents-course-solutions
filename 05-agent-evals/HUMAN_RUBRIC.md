# Human Review Rubric

Use only when deterministic checks cannot decide answer usefulness. Score 0–2 each for factual support, directness, and calibrated uncertainty. A total of 5–6 passes. Reviewers see randomized labels `A` and `B`, not system names, and record one-sentence evidence. This submission does not use a model judge; if one is added, calibrate at least ten decisions against these human labels and report every disagreement.
