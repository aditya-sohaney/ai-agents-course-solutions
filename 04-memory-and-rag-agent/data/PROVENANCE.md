# Corpus Provenance

The six documents are synthetic fictional-campus handbooks generated by `generate_corpus.py`. They contain no personal, copyrighted, or externally scraped data. The repetitive case records are intentional: they produce a corpus over 6,000 words while keeping every factual claim inspectable for a classroom RAG exercise.

Run `python generate_corpus.py` to recreate the same files byte-for-byte. Generated Markdown is ignored because the generator is the canonical source.
